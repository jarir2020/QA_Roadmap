# Tools coverage

This folder contains lightweight coverage materials (run commands + checklists) for SQA tools mentioned in `SQA_Learning_Plan.md`.

## Theory: tools provide evidence through different lenses

A tool automates a specific observation or workflow; it does not replace the test question or the judgment needed to interpret its output. Browser reports, dependency findings, accessibility violations, and load metrics each cover different risk areas. Record the target, version, configuration, and limitations so another person can understand what the result does and does not establish.
