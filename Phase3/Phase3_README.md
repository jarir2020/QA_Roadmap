## Theory focus

Web quality depends on the interaction among layout, browser behavior, input method, and assistive technology. Treat each environment as a test dimension and select combinations based on user reach and technical risk; exhaustive device-browser combinations are usually impractical. When a discrepancy appears, reproduce it with a recorded viewport, browser, OS, route, and input method.

Phase 3's checklist and report now explain why viewport evidence, browser identity, keyboard behavior, focus, and accessibility observations are separate dimensions.
