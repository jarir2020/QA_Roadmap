# Phase 7 — Alternative automation frameworks

This folder contains example tasks to learn alternatives to Playwright.

## Goal
- Understand *what each tool is best at*
- Build a tiny learning demo plan (not necessarily full automation)

## Theory focus

Automation frameworks are ways to control a browser, synchronize with page state, express assertions, and diagnose failures. Tool choice should follow the team's application, language, browser matrix, existing skills, and reporting needs. A small proof of concept can expose fit and setup costs, but broader claims need evidence across more than one scenario.

The Phase 7 documents now treat Selenium and Cypress as options to evaluate against shared criteria rather than as universally ranked tools.
