## Target
AuthDemo as the baseline app.

## Added examples
- Accessibility mini-checks
- Visual/basic regression checklist
- Localization basics (light)

## Theory focus

Specialized quality checks examine properties that ordinary functional assertions may miss. Accessibility checks whether information and controls work across interaction modes; visual regression checks whether rendered appearance changed; localization checks whether content and data conventions fit a locale. These areas overlap with functionality but require their own expectations and evidence.

The Phase 12 artifacts now explain the scope and limitations of each method, including the current screenshot comparator's exact-image behavior and the demo's English-only limitation.
