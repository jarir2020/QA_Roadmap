# Phase 6 — UI automation (Playwright)

This folder contains Phase 6 deliverables to practice **UI automation** concepts using the login/registration flow from AuthDemo.

## Target app
AuthDemo

## Deliverables
- Suggested Playwright test plan (scenarios)
- Example test spec structure (no heavy dependencies)

## Theory focus

Browser automation observes a user journey through the browser's real event, rendering, and cookie behavior. It gives strong confidence in critical paths but is slower and more environment-sensitive than tests at the function or HTTP boundary. Keep end-to-end cases focused on the most important workflows and move broad edge-case combinations to faster layers where practical.

The Phase 6 documents now cover locator stability, automatic waiting, isolated data, browser installation, and the limits of negative assertions.
